# PromedioPro

Calculadora de promedio de notas online para estudiantes de educación superior.  
Calcula promedios ponderados y simples de forma rápida, clara y gratuita.

🌐 **Live:** [https://promediopro.com](https://promediopro.com)

---

## Descripción

PromedioPro es una herramienta web diseñada para ayudar a estudiantes universitarios y de institutos a calcular su promedio académico al instante, sin hojas de cálculo ni fórmulas manuales.

---

## Características

- **Promedio ponderado** — por porcentajes, el sistema más usado en universidades
- **Promedio simple** — para institutos y cursos con igual peso por nota
- **Escalas académicas** — 0-20, 0-10, 1-7 (Chile) y 0-100
- **Nota mínima configurable** — ajusta la nota aprobatoria de tu institución
- **Predictor de examen final** — calcula cuánto necesitas en tu último examen para aprobar
- **Guardado automático** — tus notas se guardan en `localStorage`, sin perder datos al cerrar
- **Compartir por WhatsApp** — envía tus resultados con un mensaje pre-armado y link
- **Tarjeta de imagen descargable** — genera una card de resultados tipo Spotify Wrapped
- **URL compartible** — genera un link con tus notas codificadas para compartir el estado exacto
- **Modo ciclo** — selector de escala con cambio inmediato de UI y validaciones
- **Diseño responsive** — optimizado para móvil y escritorio

---

## Tecnologías

- HTML5, CSS3, JavaScript (Vanilla)
- Google Fonts (Inter + Outfit)
- Canvas API (generación de imagen)
- Web Share API (compartir imagen en móvil)
- LocalStorage (persistencia)
- Deploy en Netlify
